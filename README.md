# for_openai_codex_2025

This repository contains a simple example of wind field downscaling using Python.
The `wind_downscaling.py` script performs bilinear interpolation on coarse wind
fields (U and V components) to produce a higher resolution grid. It relies only
on the Python standard library.

## Usage

Run the script with Python 3:

```bash
python3 wind_downscaling.py
```

The script will print a demonstration of downscaling a small synthetic wind
field.
